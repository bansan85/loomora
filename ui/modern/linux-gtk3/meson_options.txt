# is used, which keeps the executable small and its glibc requirement as low as the build host

# (docs/implementation/adr/0004-fallback-per-case.md). Declared in docs/implementation/validation/fallbacks.json.

       description: 'Link the C++ runtime (libstdc++, libgcc) statically')
